## About The Project

Python is a collection of python questions that i solve while learning and improving my problem-solving skills.

I use this repo to practice what i learn and keep my solutions in one place.

Whenever i learn something new or find a new question, i add it here and try to solve it myself.

### Features

* **Topic Based Questions** - Questions are grouped by different python topics.

* **My Solutions** - Each question includes my own solution.

* **New Problems** - I keep adding questions as i continue learning.

* **Open For Practice** - Anyone can read the questions and try solving them.

## Getting Started

There is nothing special to set up.

You just need Python installed if you want to run the solutions.

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/kunjannpokhrel/Python.git
   ```

2. Enter the project directory:

   ```sh
   cd Python
   ```

## Usage

Choose a topic, open a question, and try solving it yourself.

```text
read → think → solve → add
```

The questions are there for anyone to practice, while the solutions show how i solved them.
